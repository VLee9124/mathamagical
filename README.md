# MathaMAGICal project page

Static project page for *MathaMAGICal: Validating Trajectory Data Attribution During Capability Acquisition* (ATTRIB Workshop, NeurIPS 2026).

Live at https://vlee9124.github.io/mathamagical/

Plain HTML, CSS, and JavaScript with no build step. To preview locally:

```bash
python3 -m http.server 8765
```

Numbers on the page come from the paper's tables; the accuracy curve and scatter points are recovered from its figures.
